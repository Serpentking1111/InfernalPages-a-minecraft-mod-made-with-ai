here, so the download link never changes between versions.

## Download

Click [`infernalpages-1.13.7.jar`](infernalpages-1.13.7.jar), then press the **Download raw file**
button (the ⤓ icon, top right of the file view).

Direct link:

```
https://github.com/Serpentking1111/InfernalPages-a-minecraft-mod-made-with-ai/raw/master/latest/infernalpages-1.13.7.jar
```

## Installing

Drop the jar into your `mods/` folder. It is a **Fabric** mod for **Minecraft 1.21.11**, and it
needs these installed alongside it — they are *not* bundled:

| Requirement | Version |
|---|---|
| Fabric Loader | 0.19.3+ |
| Fabric API | 0.141.6+ |
| GeckoLib | 5.4.5+ |

Without Fabric API and GeckoLib the game will crash on startup.
